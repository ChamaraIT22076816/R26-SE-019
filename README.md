# Transformer-Based Real-Time Bidirectional AI System for Deaf and Hearing Community

**Project ID:** R26-SE-019  
**Research Project:** B.Sc. (Hons) Degree in Information Technology (Specialized in Software Engineering)  
**Institution:** Sri Lanka Institute of Information Technology (SLIIT)  
**Timeline:** March 2026 – December 2026

---

## Overview

This research project proposes an integrated, transformer-based AI system that enables seamless, real-time, two-way communication between Deaf and hearing individuals. Unlike existing unidirectional solutions (speech-to-text or sign-to-text only), this system provides a complete conversational loop while also enhancing personal safety through intelligent environmental awareness.

The system addresses critical gaps in assistive technology: lack of bidirectional communication, neglect of emotional/prosodic information, absence of environmental safety features, and severe under-resourcing of Sri Lankan Sign Language (SSL).

---

## Key Features

### 1. Sign Language Recognition & Speech Output
- Real-time video-to-sign recognition using spatial-temporal transformer architectures
- Continuous signing recognition with co-articulation modeling
- Adaptive on-device personalization that learns individual signing styles
- Natural text-to-speech output with prosody preservation
- **Target:** ≥90% accuracy, <300ms latency

### 2. Speech-to-Sign Linguistic & Prosodic Processing
- Multi-stage NLP pipeline extracting grammar, emotion, and prosody
- 5-class emotion detection (happy, sad, angry, surprised, neutral)
- High-fidelity 3D avatar with emotion-driven facial expressions and body movements
- **Target:** ≥85% emotion accuracy, <300ms latency

### 3. AI-Powered Sound Awareness & Emergency SOS
- Compressed CNN-Transformer classifier for localized Sri Lankan hazard sounds
- Real-time directional localization using TDOA algorithms
- Multi-tiered low-power listening for 24/7 operation (≤10% daily battery)
- Automated GPS-tagged SOS alerts to predefined contacts
- 360° radar visualization with priority-coded haptic feedback
- **Target:** ≥85% detection accuracy, ≤5% false positives

### 4. Interactive Sign Language Learning Module
- Real-time gesture feedback using the recognition engine
- Adaptive AI-driven corrective guidance
- Personalized progress tracking
- Gamified simulations for realistic conversation practice
- **Target:** ≥20% improvement after 10 sessions
